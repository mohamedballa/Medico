## M0 — what the implementing agent did

**Runtime:** ~22 minutes.  
**Branch:** `cursor/m0-cleanup-hardening-3782` (5 commits on top of `main`).  
**Environment:** local checkout `~/projects/Medico`; PHPUnit inside the Sail container.

### Research notes (agent)

Consulted Laravel 12 signed URLs / `signed` middleware, `shivammathur/setup-php`, Inertia error-page pattern, and framework source for `enum()->change()`.

**`enum()->change()` is not valid on PostgreSQL.** It emits `ALTER COLUMN ... TYPE varchar CHECK(...)`, which Postgres rejects. Hence a **driver-aware** migration:

- PostgreSQL: drop and re-add `questions_type_check`.
- SQLite: `enum()->change()` table rebuild.

The migration **aborts** if any row has a type outside `[mcq, true_false]` instead of silently remapping content. Verified up and down against live Postgres (**0 rows** affected at the time).

### Strategy

- Git: `main` reset to `Dashboard`, dropping only the throwaway “Testing” commit that replaced `Home.jsx` with “Hello World”; force-pushed.
- Deleted **local and remote:** `Auth`, `Folio`, `Module`, `Pages`, `Progress`, `Questions`, `Recall`, `develop`.
- Product code went to the feature branch, not straight onto `main`.

### Writes and IDOR

- `DB::transaction` around question+choices and folio+slides.
- `choices.*.id` / `slides.*.id` validated with `Rule::exists()->where(parent_id)` and updated **via the parent relation**, so a foreign id can neither pass validation nor be written.

### Nginx and Adminer

- Nginx **deleted, not fixed.** It `fastcgi_pass`’d to `laravel.test:9000`, but that container runs `artisan serve` on `:80` — there is no php-fpm.
- Adminer moved to `docker-compose.override.yml` (git-ignored; `.example` committed).

### Trade-offs the agent stated

**Pros:** `Question::TYPES` as single source of truth; no login/resend enumeration; no `is_admin` mass-assignment path; CI enforces route/page existence.

**Cons:** throttling was **per-IP** (campus NAT could 429) — addressed in M0.1. Error page is only used **outside debug mode** by design (`APP_DEBUG=true` still shows Laravel’s exception page).

| Finding | Fix |

| 44 feature tests (460 assertions); CI PHPUnit on in-memory SQLite | First CI run failed because tests rendered Blade `@vite` with no manifest → `withoutVite()` on `TestCase` |

### Security review the agent claimed

Mass assignment, IDOR on child ids, enumeration, unvalidated uploads, transaction atomicity. Suite passed locally with the Vite build removed and with a fresh `.env` from `.env.example`. `npm run build` passed. `docker compose config` valid.

## M0.1 — spec (follow-up after M0 on `main`)

New branch off `main`. Do not touch admin colors.

1. Replace every `Model::create($request->all())` / `->update($request->all())` in `app/Http/Controllers/Admin/*` with `$validated`. Feature test per controller: unexpected fields (`is_published=1`, `id=999`) ignored.
2. Rewrite `MedicoSeeder`: `question_text` and `explanation` as Editor.js documents:

   ```json
   {"time":…,"blocks":[{"type":"paragraph","data":{"text":"…"}}],"version":"2.31.0"}
   ```

   Remove hard-coded `user_id => 1` and any progress/streak rows (progress is written by the app in M4). Admin users only via `php artisan medico:make-admin`. `migrate:fresh --seed` must succeed on clean Postgres **and** SQLite.

3. Login / signup / forgot throttling: key on **email + IP** (`RateLimiter::for` with `Str::lower($request->email).'|'.$request->ip()`), not IP alone (campus NAT). Keep a looser per-IP ceiling (e.g. 60/min) as a second limiter.

4. `Home.jsx`: six `/Demo` → `/Signup`; three `/Subscribe` → `/Signup` for now. No other Home changes (rebuild is M5).

## M0.1 — what the implementing agent did

**Runtime:** ~6 minutes 44 seconds.  
**Branch:** `cursor/m0-1-followup-3782` (4 commits).  
**CI:** three jobs green — PHP tests, PostgreSQL fresh-seed, frontend build.  
**Merge:** not done at report time; agent waiting for “merge `--no-ff` like last time.”

### 1. `$request->all()` → `$validated`

Only **`SubjectController` and `ModuleController`** still used `$request->all()`. Topic / Chapter / Folio / Question / Flashcard already used `$validated`.

`AdminMassAssignmentTest` covers **all seven** admin controllers: store + update with `is_published=1`, `id=999`, forged `created_at`. Asserts row count, real PK, untouched timestamps, no errors.

**Honest caveat (keep this):** those tests would also have passed **before** the fix, because `$fillable` already blocked those columns. The bug was latent, not exploitable. The tests pin the contract so a future `$fillable` addition does not silently widen the write surface.

### 2. Seeder

- Editor.js document shape for `question_text` / `explanation`.
- No users, no `user_module_progress`, no `user_streaks`.
- Whole run in one transaction.
- Added a `true_false` sample so both enum values are exercised.
- `SeederTest`: counts, document shape, zero users/progress.

Verified `migrate:fresh --seed` **twice** on scratch Postgres database `medico_m01_check` (created and dropped — **dev `medico` DB with 3 subjects was not touched**) and on a SQLite file.

CI now enforces:

- SQLite fresh-seed step in the tests job
- **postgres:17** service job that runs `migrate:fresh --seed` twice

### 3. Throttling

`RateLimiter::for('auth')` in `AppServiceProvider`:

- `Limit::perMinute(6)->by(lower(trim(email)).'|'.ip)`
- `Limit::perMinute(60)->by(ip)`

Applied via `throttle:auth` to **login, signup, forgot-password, reset-password, and verification resend**.

Tests:

- same email blocked at request 7 (case-insensitive)
- a different email from the same IP still allowed
- IP ceiling trips at 61
- signup and forgot share the limiter

**Judgment calls (accepted as correct):**

| Call | Reason |
|---|---|
| Signed **verify** link stays IP-keyed, loosened **6 → 60/min** | No email field on that request; signature is the real guard; 6/min would bite a lecture hall |
| Removed duplicate `Inertia::share('auth')` from `AppServiceProvider` | `HandleInertiaRequests` already shares the same value. Zero behaviour change |

Spec said `/Signup`; agent used **`/signup`**. Correct: M0 removed `Route::inertia('/Signup')`; Laravel routes are case-sensitive. Literal `/Signup` would have been nine new 404s.

Nine lines in `Home.jsx`. Nothing else in that file.

Three relative `href="Syllabus"` links **left as specified**. They resolve relative to the current path and **break on any non-root page**. Carry into **M1** (change to `"/learn"`), not M5.

Admin colors untouched.
