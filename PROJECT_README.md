## About Medico Solomedicine

Medico Solomedicine is an online medical education plateform , that provide an educatonal experiance to medical student and health profissional. Include Basic Medical Science (Anatomy , Biochemisty and Physiology) with aim to expand in the future into pathology , pharmacology and microbiology then to Internal Medicine, Surgery , Pedicatrics and OBGYN. 



## Features and Modules

- The Syllabus is divided into system like Cardiovasuclar System CVS , then chapters then modules 
- Each modules is divided into Folio\Text slides, MCQS, Recall Flashcards.
- Students Hub ; has apps , Challenge, merdell , Rapid Qustion , Recall
- leaderboard for students to face each other. 



## Architecture and Tech Stack

local environment is mac OSX 10.13 the app is run in Docker v 20.10
- Php 8.4
- Sail 8.4
- Laravel 12
- React 19.1.1
- Inertia 2.1
- Tailwindcss 3.3.2
- PostgreSQL 17



## Installlation and Setup

- using Docker and compose to install laravel app
- using docker to install sail.
- making change to install the postgresql instead of Mysql (default DB)
- building up the image using sail 
- installing inertial , react, tailwindcss
- configure the env to use custom adress medicosolomed.com
- using AI to debug (Chatgpt, Grok)
